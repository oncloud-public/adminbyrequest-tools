# Security policy

## Reporting a vulnerability

Please don't report security problems in public issues.

Report them privately through GitHub: open the **Security** tab of this repository and click **Report a vulnerability**. We'll reply as soon as we can and keep you updated until it's fixed.

## Secrets

Never put API keys, passwords or tenant details in an issue, a pull request or a commit. If you think a secret was exposed, revoke it in Admin By Request right away and then report it as above.
